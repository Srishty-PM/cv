## What this portfolio demonstrates

- **Customer journeys:** connect discovery, confidence, action and repeat use rather than treating features in isolation.
- **Product judgement:** define a focused first version, surface trade-offs and distinguish assumptions from evidence.
- **AI product thinking:** connect model output to user value, consent, evaluation, failure handling and operating cost.
- **Hands-on delivery:** translate product intent into working interfaces, data flows and measurable user events, using AI-assisted development where useful.

The project stories describe implemented capabilities, design decisions and proposed measurement. They do not claim independently verified business results for these personal projects. My professional experience and career results are on my [website](https://srishtypahujani.com/).
